# Changelog / История изменений

Все значимые изменения в проекте **ExilePace — PoE 1 PoE Heist & Path of Exile 2 Tracker PoE 2 Activity Tracker** документируются в этом файле.
Формат основан на [Semantic Versioning](https://semver.org).

## - 2026-11-23
### Изменено / Changed
- **Фоновый запуск по умолчанию (`v1.12.1`):** запуск с флагом `--overlay` теперь автоматически отвязывается от окна терминала (окно консоли можно сразу закрывать без передачи `--bg`; для привязки к консоли добавлен флаг `--fg`).
- Скрипты быстрого запуска (`start_overlay.sh`, `start_poe2_overlay.sh`, `start_overlay.bat`, `install_windows.bat`) переведены на отображение статистики текущей лиги (`league`) по умолчанию.

## - 2026-11-23
### Добавлено и изменено / Added & Changed
- **Path of Exile 2 (`v1.12.0`):** режимы **Сехем (`SEKHEMAS`)** и **Ультиматум (`ULTIMATUM`)** разделены на два отдельных экрана в оверлее с кнопкой быстрого переключения в шапке (`⇄ ULTIMATUM` / `⇄ SEKHEMAS`) и в меню трея.
- Улучшен парсинг `Client.txt` для PoE 2: входные хабы (*Trial of the Sekhemas*, *The Temple of Chaos*) больше не накручивают лишние этажи, добавлены среднее время и рекорды по обоим испытаниям.
- Добавлен флаг запуска `--ultimatum` (`--chaos`) для старта сразу в режиме Ультиматума.
- Из интерфейса PoE 2 полностью убраны элементы Heist и Blight из PoE 1.

## - 2026-11-23
### Добавлено / Added
- Парсинг `Client.txt` для **Path of Exile 1** (разделение одиночных контрактов и чертежей Grand Heist по крыльям).
- Поддержка **Path of Exile 2** (`--poe2`): трекинг Испытания Сехем, Испытания Хаоса, пинакл-боссов и карт.
- Расчет темпа фарма (забегов/час), активного времени в забегах и простоев в Гавани/Хабе.
- Фильтрация статистики по дате (`today`, `DD.MM.YYYY`, `YYYY-MM-DD`).
- Полупрозрачный перетаскиваемый оверлей поверх окна игры (`--overlay`) и живой режим в терминале (`--live`).
- Автоопределение путей к `Client.txt` для Linux и Windows с сохранением в `config.json`.
- Автоустановщик для Windows (`install_windows.bat`) и сборка автономного бинарника для Linux.

## - 2026-11-23
### Добавлено / Added
- Значок Разбойничьего жетона в системном трее (панели задач) с быстрым скрытием/показом оверлея и кнопкой выхода (`pystray`).
- Поддержка упаковки иконки внутрь автономных сборок PyInstaller (`_MEIPASS`) в GitHub Actions и `install_windows.bat`.

## - 2026-11-23
### Добавлено / Added
- Встроенная система автообновления через GitHub Releases API (`--update` / `-u`).
- Фоновая проверка новых версий при запуске оверлея (уведомление в заголовке и кнопка обновления в контекстном меню значка в трее).
- Поддержка самообновления как для Python-скрипта, так и для скомпилированных бинарников Windows (`.exe`) и Linux.

## - 2026-11-23
### Добавлено / Added
- Встроенный дебаггер и ротируемый лог-файл `tracker.log` (`--debug` / `-d`) с перехватом любых необработанных исключений (`sys.excepthook`).
- Замер скорости парсинга в режиме отладки и защита оверлея от падения при блокировке `Client.txt`.
- Пункт **«Открыть лог отладки»** в контекстном меню значка в системном трее.

## - 2026-11-23
### Изменено / Changed
- Проект официально переименован в **ExilePace** (`MuonSuzuki/exile-pace`).
- Обновлены заголовки оверлея, имена собираемых бинарников (`ExilePace-Windows.exe` / `exile-pace-linux`) и пути установки.

## - 2026-11-23
### Добавлено / Added
- Разбор реплик Сестры Кассии в режиме Скверны (`--blight`): подсчёт успешных защит насоса (`Wins`), разрушений (`Losses`) и винрейта.
- Трекинг упоминаний редких масел (`Golden`, `Silver`, `Tainted`, `Prismatic`, `Reflective Oil`) в логе.

## - 2026-11-23
### Добавлено / Added
- Кнопка мгновенного переключения режимов (**`⇄ BLIGHT`** / **`⇄ HEIST`**) прямо в шапке оверлея и в контекстном меню значка системного трея.

## - 2026-11-23
### Добавлено / Added
- Команда **`league`** (`--league`) для мгновенного вывода статистики с начала текущей лиги (PoE 1: 13.11.2026 [Covens of Umbra], PoE 2: 29.05.2026; настраивается в `config.json`).
- Динамическое масштабирование буфера чтения `Client.txt` в зависимости от давности выбранной даты (от 4 МБ для `today` до полного чтения для старта лиги).
